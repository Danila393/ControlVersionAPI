# Шрифты для PDF-отчётов

`reportlab` (см. `src/tasks/reports.py`) не умеет в кириллицу своими
встроенными шрифтами (Helvetica и т.п.) — нужен TTF-файл со всеми буквами.

`DejaVuSans.ttf` в этой папке — open-license шрифт с полной кириллицей,
закоммичен в репозиторий, ничего дополнительно скачивать не нужно.

Если файла почему-то нет, `reports.py` при генерации PDF откатывается на
системный Arial (`C:\Windows\Fonts\arial.ttf`) — это работает только на
Windows и не годится для Docker/Linux-окружения, поэтому основной вариант
— именно файл из этой папки.
